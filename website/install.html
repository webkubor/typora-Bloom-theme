如何安装 Bloom Typora 主题

Bloom 是给 Typora 的 12 浅色 + 12 深色莫兰迪主题。把主题文件放进 Typora 的主题文件夹，重启后就能在「主题」菜单里切换。下面是完整步骤和各系统的文件夹位置。

方式一：从 GitHub Releases 下载（推荐）

  1. 打开 Releases 页面，下载最新的 Bloom-theme.zip。
  2. 解压后你会看到 24 个 bloom-*.css 文件和一个 bloom/ 文件夹（字体等资源）。
  3. 把 这些文件和文件夹一起复制进 Typora 的主题文件夹。
  4. 重启 Typora，在「主题」菜单里选择 Bloom 系列，例如 花瓣·暗夜。

注意：字体在 bloom/ 文件夹里。只复制 CSS 而不复制这个文件夹，字体不会生效。

方式二：从源码目录手动复制

  1. 打开 Typora，进入「偏好设置 → 外观 → 打开主题文件夹」。
  2. 把 bloom-*.css（例如 bloom-amber.css、bloom-amber-dark.css）和 bloom/ 文件夹复制进该目录。
  3. 重启 Typora，在「主题」菜单中选择 Bloom 系列。

主题文件夹在哪

不同系统位置不同，但都可以通过上面的「打开主题文件夹」直达：

  • macOS：~/Library/Application Support/Typora/themes/
  • Windows：%APPDATA%\Typora\themes\
  • Linux：~/.config/Typora/themes/

常见问题

装完了，主题菜单里还是看不到 Bloom？

  • 确认复制的是 .css 文件本身，而不是多套了一层文件夹。主题文件夹里应当直接是 bloom-amber.css 这样的文件。
  • 确认文件名没有被改过。有些系统解压后中文名会变成别的样子。
  • 复制完成后重启 Typora，主题菜单不会自动刷新。

主题出现了，但字体没变？

字体文件在 bloom/ 目录里，需要和 CSS 一起复制。确认主题文件夹下确实存在 bloom/fonts/。
